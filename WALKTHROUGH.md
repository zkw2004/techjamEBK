# Three-minute walkthrough runbook

Track 2 does not require a video, but an approximately three-minute demo is
recommended when it helps explain the solution. This is a ready-to-record
walkthrough; use 1080p with readable terminal text. Keep a local capture as a
fallback instead of depending on live network/API access during judging.

## Before recording

```bash
make setup
make data
make check
python -m tools.report --trajectory artifacts/trajectory.png
```

Open three prepared windows: the README architecture/trust-boundary section,
`python -m tools.live --watch`, and the generated trajectory image. Never show
`.env`, API-key configuration, raw traces, or shell history containing tokens.

## Deterministic injected-failure replay

```bash
python -m tools.oom_demo
```

This does not allocate dangerous amounts of memory. It injects a controlled
`MemoryError` record with `batch_size=8192`, calls the production A5 recovery
policy, shows the logged `oom → retry` event, and renders the linked successful
node at `batch_size=4096`. The behavior is covered by an automated test.
